# 豹嗷喵 · Windows 桌宠

解压整个文件夹，然后双击 **豹嗷喵.exe**。请让 exe、pet.ico 和 assets 文件夹保持在一起。

程序使用 Windows 自带的 .NET Framework 桌面组件，不需要 Python、浏览器或联网服务。适用于 Windows 10 / 11；若系统关闭了 .NET Framework 4.x，需要先恢复该系统组件。

## 操作

- **单击角色**：播放豹嗷喵互动动画。
- **按住鼠标左键拖动**：切换为「拎起」，松开后恢复安静待机。
- **右键角色**：选择巡逻、打扫、玩苹果、弹吉他、「酷」或互动动作；也可暂停、调节大小、关闭随机动作、隐藏或退出。
- **系统托盘猫猫图标**：双击显示／隐藏；右键可找回桌宠、调整设置或退出。
- **安静待机**：沿用原图静止帧。自动动作默认开启，间隔约 8–15 秒；可从菜单关闭。
- **自主巡逻**：默认关闭。开启后沿原图朝向向右移动，到工作区边界停下；不镜像不对称角色图案。

透明区域不拦截桌面鼠标；只在角色和动画本身可见的像素区域响应。窗口默认置顶，不在任务栏占单独按钮。

位置、大小等设置保存到程序旁边的 settings.json。移动整个解压文件夹时，设置会一起移动。

## 素材与当前范围

本版接入 7 组原动画、共 126 帧，保留逐帧播放时长与原有画风。使用透明 PNG 显示，可保留半透明轮廓。为统一桌面显示比例，各动作使用固定缩放和固定画布，动作内部位移保留。

「拎起」仅包含原图右下最后一只小猫。原素材已被画布截断的脚部或音符没有补画，程序会保留原始内容。

当前是可运行原型：没有新增眨眼或呼吸动画，没有音效、联网、开机启动或注册表写入。待机使用原始首帧，不会擅自重画细节。

## 源码与构建

源码位于包内 `source/`。`build.ps1` 使用 Windows 自带的 C# 编译器，输出目录若已存在会停止，以保护旧文件。也可自行检查 `asset-processing.json` 中的固定变换和动画锚点。

程序提供素材自检 `--self-test 报告路径`，以及自动结束的透明窗口检查 `--smoke-test 报告路径`。两种检查不会写入个人设置。
